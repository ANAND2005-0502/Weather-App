
# 🌤 Weather App

A responsive Live Weather Application built using HTML, CSS and JavaScript.

## Features
- Search weather by city
- Live temperature
- Weather conditions
- Humidity information
- Wind speed
- Responsive design
- Open-Meteo API integration
- No API key required

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo API

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Run index.html using Live Server.
4. Search for any city.
